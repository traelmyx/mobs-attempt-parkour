# Mobs Attempt Parkour Updated

Mobs jump over gaps, water, lava and fire to reach you.

Updated port of [Mobs Attempt Parkour](https://github.com/miyo6032/mobs-attempt-parkour) by Barribob, whose last release was for 1.20.1. The jump AI is Barribob's. This version is rewritten in Java, has no Kotlin or library dependencies, and adds NeoForge.

- Fabric and NeoForge, Minecraft 1.21.1 and 26.3
- Server-side only
- Config: `config/mobs_attempt_parkour/config.json`, same format as the original

## Building

```
./gradlew buildAll
```

Uses [Stonecutter](https://stonecutter.kikugie.dev/) for the versions and loaders. Game tests run as part of the build.
